# Legacy Google Sheets custom-practices setup

This app no longer writes to Google Sheets or Apps Script.

Custom/manual calendar rows are now stored in `src/data/plannerData.json` under `calendarRows`, and local UI edits are saved by the Vite dev server when running `npm run dev`.
